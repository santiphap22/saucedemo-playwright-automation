# E2E Test Automation Framework - Swag Labs (SauceDemo)

## Project Overview

This repository contains an End-to-End (E2E) automated testing suite designed for the Swag Labs (SauceDemo) web application using **Playwright** with **TypeScript**.

The framework is structured to demonstrate scalable test design, robust locator practices using custom test IDs, dynamic state assertions, and automated error handling across core e-commerce workflows.

---

## Technical Specifications

* **Test Runner:** Playwright
* **Language:** TypeScript
* **Target Application:** SauceDemo (https://www.saucedemo.com/)
* **Design Pattern:** Modular Test Scripts
* **Assertion Engine:** Playwright Built-in Expect Assertions
